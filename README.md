# 부산 영화관 탐험대

초등학교 4학년이 부산의 영화관을 조사하고, 문화 공간으로서 지역 사람들의 생활에 주는 도움을 생각하는 웹앱입니다.

- **롯데시네마 동래점**: 2026년 11월 26일(목)에 방문할 곳
- **영화의전당**: 1학기에 다녀온 곳
- **모퉁이극장**: 새롭게 알아보며 비교할 곳

## 사용 순서

1. 영화관 또는 집·학교에서 함께 영화를 본 경험을 적습니다.
2. 영화의전당의 1학기 방문 경험을 떠올립니다. 자료에서 새롭게 알게 된 시설과 실제 방문했던 시설은 구분합니다.
3. 위쪽 가로줄에서 영화관을 고릅니다. **사진 / 읽기 자료**를 바꿔 보고, 이전·다음 버튼이나 작은 사진을 눌러 자료를 넘깁니다. 사진을 누르면 큰 사진 보기에서 원본 전체와 출처를 볼 수 있습니다.
4. 특징을 찾고, 이를 확인한 자료의 **근거 담기** 버튼을 누릅니다. 아래쪽 **나의 기록장**을 열어 특징과 사람들에게 주는 도움을 자기 말로 씁니다. 기록은 자동으로 저장됩니다.
5. **나란히 비교**에서 친구와 공통점·차이점을 이야기합니다. 전자칠판에서는 **발표 화면 크게**를 사용할 수 있습니다.
6. 영화관이 사라지면 달라질 일을 생각하고, 근거와 자신의 생각을 연결해 영화관의 의미를 씁니다.
7. **나의 기록**에서 이미지(PNG), 인쇄/PDF, 글 복사로 결과물을 보관합니다.
8. 11월 26일 방문 뒤 **나의 기록** 하단에서 실제 관찰과 달라진 생각을 덧붙입니다. 저장하는 결과물에도 포함됩니다.

## 40분 수업 운영

경험 나누기 5분 → 자료 조사 15분 → 비교·의미 토의 15분 → 정리 5분.

6모둠이라면 같은 영화관을 두 모둠씩 조사할 수 있습니다. 같은 자료를 보더라도 찾은 특징이나 해석이 다를 수 있습니다. 다른 영화관 기록이 비어 있어도 저장할 수 있습니다.

## GitHub + Vercel 배포

이 압축파일의 **내용물**을 GitHub 저장소의 최상위에 올립니다. index.html, app.js, data.js, styles.css, tablet.css, assets 폴더가 같은 위치에 있어야 합니다.

1. GitHub에서 새 저장소를 만들고 **Add file → Upload files**에서 압축을 푼 내용물을 올립니다. ZIP 자체를 올리는 방식이 아닙니다.
2. Vercel에서 **Add New → Project**로 저장소를 가져옵니다.
3. **Framework Preset: Other**로 둡니다.
4. Root Directory는 저장소의 기본 위치로 둡니다. 빌드·설치 명령은 필요하지 않습니다. Output Directory를 별도로 요구하면 `.`을 사용합니다.
5. **Deploy**를 누릅니다.

Firebase·로그인·환경 변수·유료 API가 필요하지 않습니다. 학생들은 배포된 공통 주소에 접속합니다. 이 프로젝트의 실행 파일에는 npm 패키지나 외부 CDN 스크립트 의존성이 없습니다. 사진도 프로젝트에 포함되어 있으므로 조사 중 사진을 보기 위해 원본 사이트를 다시 불러오지 않습니다.

## 저장과 공유

- 기록은 기기·브라우저·사이트 주소별로 localStorage에 저장됩니다. 같은 모둠을 골라도 여러 기기의 기록이 합쳐지지는 않습니다.
- 공통 주소에 접속하는 다른 학생의 기록과 섞이지 않습니다. 같은 기기의 같은 브라우저를 여러 학생이 번갈아 쓰면 같은 기록이 보입니다.
- 교사에게 자동 제출하거나 교사 화면에 실시간으로 모으는 기능은 없습니다. PNG·PDF·복사한 글을 학교에서 쓰는 제출 도구로 전달합니다.
- 다른 기기에서 계속 쓰려면 **이어 쓰기 파일 저장(JSON)** 후 새 기기에서 **이어 쓰기 파일 열기**를 선택합니다. 파일을 열기 전 현재 기록을 저장할 수 있습니다.
- 브라우저가 저장을 막거나 저장 공간이 부족하면 상단에 임시 기록 안내가 나타납니다. 이 경우 내려받기 기능으로 보관합니다.
- 배포 주소를 바꾸거나 브라우저 데이터를 지우기 전에 JSON 파일을 저장하세요.

## 학급과 체험일 수정

**안내 · 설정**에서 학급, 체험일, 정해진 영화 제목을 입력할 수 있습니다. 여기서 바꾼 설정은 현재 기기에만 적용됩니다.

모든 기기에 적용되는 초기값은 `app.js`의 `fresh()` 함수에서 `settings`를 수정합니다. 기존에 작성한 기기의 기록을 자동으로 덮어쓰지는 않습니다.

영화관 설명·사진·근거 자료·원문 링크는 `data.js`에서 수정합니다. 당시 상영 영화나 운영 시간은 고정 자료로 넣지 않았습니다. 영화 제목과 체험 당일 이용 상영관은 학교의 실제 계획에 따라 정합니다.

## 자료

공식 정보를 2026년 10월 30일 확인하고 어린이용으로 요약했습니다. 롯데시네마 동래점의 상영관·좌석 수는 이날의 공식 지점 안내 기준입니다. 사진과 설명의 상세 출처는 `SOURCES.md`와 웹앱 **사진 · 자료 출처**에 있습니다.

기본 화면은 갤럭시탭의 가로 방향을 중심으로 구성했습니다. 주요 본문은 19~21px, 버튼과 입력칸은 18~21px를 사용합니다. 영화관 선택은 가로줄, 조사 자료는 사진과 설명을 나란히 배치하며, 기록장은 큰 창으로 엽니다. 경험·비교·의미 쓰기도 한 항목씩 고르는 탭으로 세로 스크롤을 줄였습니다. 작은 화면에서는 세로로 이어집니다. 사진·원문·지도는 새 탭에서 확인할 수 있습니다. 상영관 내부나 상영 중 화면의 촬영을 요구하는 활동은 넣지 않았습니다.

## 사진 구성 (2026-10-30 개선)

- 롯데시네마 동래점: 건물 외관, 백화점 출입구, 백화점 내부 등 **3장**. 백화점 내부 사진을 영화관 로비 사진으로 표시하지 않습니다.
- 영화의전당: 전경, 라이브러리, 감독 역할 체험, 공연 등 **4장**. 체험·공연은 2020년 소개 자료이며 현재 운영이나 우리 반의 방문 활동을 뜻하지 않습니다.
- 모퉁이극장: 건물 외관, 포스터 계단, 매표 공간 등 **3장**. 사진 속 포스터는 촬영 당시의 모습입니다.

추가 전 기록과 이어 쓰기 파일은 그대로 사용할 수 있도록 저장 키·자료 ID·JSON 형식을 유지했습니다. 사진 원본은 자르거나 편집하지 않았습니다.
