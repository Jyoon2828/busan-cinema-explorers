# 부산 영화관 탐험대 — 자유 선택·의미 탐구

부산의 초등학생 누구나 관심 있는 영화관을 골라 특징을 조사하고, 영화관이 사람들에게 주는 즐거움과 함께 보는 경험의 가치를 생각하는 수업용 웹앱입니다.

## 조사할 수 있는 6개 영화관

| 영화관 | 살펴볼 특징 |
| --- | --- |
| 롯데시네마 동래점 | 생활 속 영화관 |
| 영화의전당 | 영화·공연·배움 |
| 모퉁이극장 | 독립·예술영화와 대화 |
| 밀락수변 바다영화관 | 바다 곁 야외 상영·헤드셋 |
| CGV 센텀시티 IMAX | 큰 화면·레이저 영사·음향 |
| CGV DRIVE IN 영도 | 자동차 관객석·라디오 청취 |

학생은 여섯 곳 중 관심 있는 영화관을 자유롭게 고릅니다. 같은 영화관을 여러 학생이 선택할 수 있으며, 다른 영화관 자료도 언제든 살펴볼 수 있습니다. 자료 사진·공식 홍보 이미지·공식 소개영상 표지 17개와 조사자료 29개를 포함합니다.

## 수업 흐름

1. **경험 나누기**: 가족·친구와 함께 영화를 본 경험과 마음에 남은 순간을 떠올립니다. 영화관에 가 본 적이 없어도 집이나 학교에서 본 경험을 쓸 수 있습니다.
2. **영화관 조사**: 위쪽의 여섯 영화관 중 원하는 곳을 고릅니다. 사진/읽기 자료를 넘겨 보고 사진을 확대합니다. 특징을 확인한 자료를 근거로 담고 ‘나의 기록장’에 특징과 사람들에게 주는 도움을 씁니다.
3. **의미 찾기**: 세 주제의 질문 9개 중 필요한 질문을 골라 생각을 씁니다. 모두 답할 필요는 없습니다. 마지막에 지역 영화관의 의미를 한 문장으로 정리합니다.
4. **나의 기록**: 작성한 조사 내용과 의미에 대한 생각을 읽고 보관합니다. 기록 이미지(PNG)와 인쇄/PDF에는 조사한 영화관 사진이 함께 들어갑니다. 글 복사는 작성한 글을 보관합니다.

권장 40분 흐름: 경험 나누기 5분 → 자료 조사 15분 → 의미 생각하기·나누기 15분 → 정리 5분.

## 의미를 생각하는 질문 9개

### 사람들에게 주는 즐거움

- 큰 화면과 좋은 소리로 영화를 보면 어떤 즐거움을 느낄 수 있을까요?
- 영화관에서 가족이나 친구와 보내는 시간은 왜 특별할까요?
- 영화 속 새로운 이야기나 인물의 삶을 만나면 무엇을 느끼거나 배울 수 있을까요?

### 함께 보는 경험의 가치

- 같은 장면을 함께 보며 웃거나 감동하면 어떤 점이 좋을까요?
- 영화가 끝난 뒤 서로 다른 생각과 감상을 나누면 무엇을 알 수 있을까요?
- 여러 사람이 함께 영화를 즐기려면 어떤 배려가 필요할까요? 그 배려는 왜 중요할까요?

### 우리 지역의 문화 공간

- 영화관이 우리 지역 사람들이 함께 문화를 즐기는 장소가 되면 어떤 점이 좋을까요?
- 우리 지역에 영화관이 있으면 사람들이 어떤 문화 활동을 더 쉽게 경험할 수 있을까요?
- 우리 지역에서 영화관이 사라진다면, 어떤 즐거움과 함께하는 경험이 줄어들까요?

### 한 문장으로 정리하기

“우리 지역 영화관은 ______을/를 함께 경험하는 문화 공간입니다.”

정답을 미리 채우지 않습니다. 학생이 조사한 특징과 근거, 자신의 경험을 연결해 자기 말로 씁니다. 질문에 쓴 생각과 최종 문장은 저장하는 결과물에 포함됩니다.

## GitHub + Vercel 배포

압축을 푼 **내용물 전체**를 GitHub 저장소의 최상위에 올립니다. ZIP 자체를 올리는 방식이 아닙니다. index.html, app.js, data.js, styles.css, tablet.css, six-cinemas.css, cute.css, tablet-fit.css, assets 폴더를 함께 올려야 합니다. 기존 저장소를 수정할 때도 새 파일을 포함해 덮어 올립니다.

1. GitHub 저장소의 Add file → Upload files에서 내용물을 올립니다.
2. Vercel에서 Add New → Project로 저장소를 가져옵니다.
3. Framework Preset은 **Other**로 설정합니다.
4. Root Directory는 기본 위치로 둡니다. 설치·빌드 명령은 필요하지 않습니다. Output Directory를 요구하면 `.`을 사용합니다.
5. Deploy를 누릅니다. 기존 Vercel 연결이 있으면 기존 프로젝트를 갱신합니다.

Firebase, 환경 변수, 유료 API, 학생 로그인이 필요하지 않습니다. 사진도 프로젝트 안에 포함되어 있습니다. 외부 사진 서버에서 실시간으로 읽지 않습니다.

## 저장과 기록 이어 쓰기

- 기록은 기기·브라우저·사이트 주소별로 현재 브라우저에 자동 저장됩니다.
- 다른 기기의 기록과 합쳐지거나 교사에게 자동 제출되지 않습니다. 저장한 파일이나 복사한 글을 학교에서 사용하는 제출 도구로 전달합니다.
- 다른 기기에서 계속 쓰려면 이어 쓰기 파일(JSON)을 저장한 뒤 새 기기에서 엽니다.
- 브라우저 데이터를 지우거나 배포 주소를 바꾸기 전에 이어 쓰기 파일을 저장합니다.
- 이전 버전의 영화관 조사, 경험, 의미 정리, 체험 후 기록은 이어집니다.
- 영화관에 직접 다녀왔다면 ‘나의 기록’ 하단에 실제 관찰과 달라진 생각을 선택하여 덧붙일 수 있습니다. 특정 학교나 방문 일정은 정해져 있지 않습니다.
- 이름 또는 별명은 선택 사항입니다. 학급이나 학교 정보를 입력하지 않아도 사용할 수 있습니다.
- 저장하는 기록에는 각 영화관에서 근거로 담은 사진이 모두 들어갑니다. 사진을 근거로 담지 않았다면 해당 영화관의 대표 사진이 들어갑니다. 사진은 원본 전체를 보여 주며 자르지 않습니다.

## 태블릿 화면과 자료

하늘색·바다색과 흰색을 중심으로, 모눈 배경과 둥근 카드로 꾸몄습니다. 첫 화면은 거학이가 영화관 탐험을 안내하며, 조사 자료에는 실제 영화관 사진이 들어갑니다.

가로 태블릿에서는 영화관 여섯 곳을 3칸×2줄로 표시하고, 사진과 설명을 나란히 보여 줍니다. 기록장은 큰 창으로 엽니다. 의미 질문은 주제별로 나누어 선택하고 큰 입력창에 기록합니다.

기존 세 곳은 2026년 10월 30일, 추가 세 곳은 11월 4일 공식 자료를 확인했습니다. 사진별 출처와 이용 조건은 SOURCES.md 및 웹앱의 사진·자료 출처에서 확인합니다. 영상 표지는 정지 이미지로 표시합니다. 자료 사진은 촬영 당시의 모습을 보여 줍니다. 야외 영화관의 실제 운영 날짜·시간·기상 변동은 공식 안내를 확인합니다.

## 학생 기록의 출처 표시

학생이 저장하는 PNG 이미지, 인쇄/PDF, 복사한 글에는 하단에 “자료 출처: 영화관 공식 안내 및 공공기관 자료 참고” 한 줄만 표시합니다. 자세한 원문 링크와 사진 출처는 앱의 사진·자료 출처 및 SOURCES.md에서 확인할 수 있습니다.

## 태블릿 화면 구성

태블릿에서는 경험 화면을 좌우로 나누어 캐릭터와 입력창을 한 화면에 배치합니다. 영화관 자료와 의미 질문은 탭·이전/다음 버튼으로 넘깁니다. 나의 기록은 사진과 핵심 내용을 먼저 보여 주고, 전체 글은 ‘전체 기록 미리보기’에서 확인합니다. 긴 글은 입력창·미리보기 안에서 스크롤하며, 저장 파일에는 작성 내용과 선택 사진이 모두 들어갑니다. 선택 사항인 방문 후 기록은 별도 창에서 작성합니다.
